## Architecture (from Add. 20 — what is load-bearing vs deferred)

**The wiki's runtime is the deliverable** — vendored lang-core, wiki Lit component
library (Lit-rendered), toolProvider bridge to existing services, state
hydrate/flush through ArtifactStateService, @ToAssistant → SendMessage, mergeStatements
**host-side** (Add. 21: Go has no JS runtime; no MergeArtifactPatch RPC).
No iframe, no per-route CSP/MIME surface, no asset dir — the host renders in-page
via bundled Lit components. The app is a stored Lang program (`lang = "openui-lang"`,
library = `wiki-core@1`, source in a ` ```wiki-artifact ` markdown fence).

Deferred to the v2 html cutover issue (never built here, per Add. 20's deletion plan):
html fence mode, srcdoc host path, multi-file asset dir, `/artifact/` route with
CSP/nosniff/manifest MIME, SplitArtifactFences template choke-point work, window.wiki
shim, ADR-0014 posture change. **Lang mode has none of that** — the runtime renders
in-page; the agent's program is data.

## Acceptance criteria (all from the issue body + Addenda, Lang-primary scope)

1. Agent writes Lang program via SetArtifact; page renders **app above prose** (app-alone when prose cleared) via bundled lang-core parser + wiki Lit components; no arbitrary HTML/JS executes; invalid/unknown statements drop (Lang robustness).
2. Agent's OpenUI Lang system prompt shipped by the wiki (`help_artifacts_lang`, generateSystemPrompt output over wiki library spec); `wiki.artifact.library` pins the spec.
3. Iteration: agent patch → host merges (mergeStatements) → SetArtifact (base OCC) → WatchArtifact → hot-swap without reload; state bindings intact.
4. State CAS'd + watchable via ArtifactStateService; concurrent writers surface OCC conflicts, never silent loss; localStorage is not a state path.
5. @ToAssistant in program → chat message on page; agent reply hot-swaps.
6. Validation funnel: bad program fails **any** write path (`SetArtifact` via tools, `/edit` → UpdatePageContent) with structured error; previous version still renders; no route writes an unvalidated fence.
7. Placement enforced mechanically: SetArtifact/edit-path prose-clear dropping >10% of substantial prose without confirm_replace_content fails (FailedPrecondition). Idempotent on app-only pages.
8. Reserved-namespace rejection error names the right dedicated service (refine reservedNamespaceMessages["wiki"], test-pinned).
9. Frontmatter editor dialog disabled on artifact pages.
10. One history: program + prose ride ADR-0016 page snapshots; no separate artifact history.
11. Search & view agree: indexes prose with fence removed; rendered prose likewise has fence removed; searched text is visible below the app.
12. Every W1–W7 workflow has a failing→passing home in eval/cases.go or e2e/tests.
13. help_artifacts_lang shipped (library spec + generated prompt + canonical example + runtime contract + composition model), For-Agents house voice, `[[help]]` index entry.
14. Renderer integration: Lit-bound wiki components render a parsed Lang program end-to-end above prose (ADR-0017 records path decision + architecture + scope cuts).

## Design corrections embedded (from the issue's addenda — do NOT regress these)

- **State OCC is namespace-scoped, not page-markdown-scoped** (Add. 1/2): two tabs of one artifact must conflict with each other, not with unrelated page markdown edits; state service has its own hash.
- **WatchArtifact is required**, not polish (Add. 2): without it, "agent edits and app updates" silently doesn't propagate.
- **SplitArtifactFences = two outputs** (Add. 23): fence content (never rendered/indexed) AND prose remainder with fence removed (what goldmark renders, Bleve indexes, executors process). Without removal the prose section renders the whole Lang program as a literal code block.
- **Fence stripping is removal from rendered prose, not just template bypass** (Add. 23 / criterion 11).
- **Templating choke points** (Add. 2): fence strip lives inside `templating.ExecuteTemplate` + `templating.ValidateTemplate`, not at individual call sites — future callers inherit it.
- **Placement guard is mechanical** (Add. 15): API enforces what docs teach, idempotent on app-only pages, fires only on prose→app transitions.
- **MergeArtifactPatch removed** (Add. 21): Go has no JS runtime; mergeStatements is host-side; server is validator+stamper only.
- **CommitArtifact/GetArtifactLog removed** (Add. 13): ADR-0016 page snapshots are the only history.
- **toolProvider is an allowlist**, not "etc." (Add. 24): hard-coded, test-enforced; destructive intent routes through @ToAssistant→chat loop, never the toolProvider.
- **Frontmatter editor disabled on artifact pages** (Add. 3): load strips reserved subtrees; save races artifact services.
- **Composition, never XOR** (Add. 22): always render prose; prepend artifact host; search hit is always visible on the page.
