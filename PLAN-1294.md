### Component changes (`static/js/openui-lang/library.ts`)

1. **Text** gains size variants: `variant` prop, `z.enum(['title','body','caption']).optional()`
   (append AFTER `content` so positional `Text("...")` keeps binding). Adds
   `data-variant` attr; CSS classes `.wiki-page-app-text[data-variant=…]`:
   title 1.25rem/650, body default, caption 0.8rem + secondary color.
2. **Button** gains `variant`: `z.enum(['primary','secondary','ghost','danger']).optional()`,
   default `primary`. Adds `data-variant` attr; CSS:
   - primary: current blue confirm button (unchanged).
   - secondary: `--color-action-secondary-bg` bg, `--color-text-secondary` text,
     `--color-border-default` border; hover `--color-action-secondary-hover-bg`.
   - ghost: transparent bg, `--color-action-confirm` text; hover `--color-hover-overlay`.
   - danger: `--color-action-danger` bg, hover `--color-action-danger-hover`.
3. **Stack** `gap` prop: keep free-string form for BC but ADD recommended-token
   support — accept `'sm'|'md'|'lg'|'xl'` mapping to 4/8/16/24px via
   `z.union([z.string(), z.enum(['sm','md','lg','xl'])])` (gap stays after children
   in props so positional `Stack([...])` is untouched). Card body/card
   gap `10px` → `12px` (4pt grid).
4. **Progress** (new, wiki-native read surface): props `(total, current, label?)`,
   `current` reactive (`markReactive`). Renders "N of M" + a progress bar div
   (`role=progressbar` + aria-valuenow/max). Positional order: `total`, `current`,
   `label` so `Progress($total, $done, "steps")` binds naturally.
5. **Steps** (new): `current`, `total`, `label?` — "step 2 of 5" text with
   back/next Buttons wired via `onBack`/`onNext` actions (both optional; buttons
   render only when the action is provided, disabled when at range edges
   only if the action exists — no, keep simple: render buttons only when
   action provided; edge-clamping stays in program logic). Positional order:
   `current`, `total`, `onBack?`, `onNext?`, `label?` — matching common use
   `Steps($i, 3, @Set($i, $i - 1), @Set($i, $i + 1))`.
6. Register both in `childrenUnion` + `components` array.

### Styling (`static/js/openui-lang/page-app-design-system.ts`)

- New classes: `.wiki-page-app-progress`, `.wiki-page-app-progress-label`,
  `.wiki-page-app-progress-bar`, `.wiki-page-app-progress-fill`.
- New classes: `.wiki-page-app-steps`, `.wiki-page-app-steps-label`.
- Button variant selectors `[data-variant=…]`, text variant selectors.
- All spacing values move to the 4pt grid (6px gaps in chart rows stay —
  inside a labeled figure, they are gaps within a row, not card rhythm; document).

### Token fixes (AA contrast)

- Light `--color-text-muted`: `#999999` → `#737373` (4.74:1 on #fff, 4.50:1 on
  #f8f9fa — passes AA on both light surfaces).
- Dark `--color-text-muted`: `#8b949e` → `#999b9e` (4.94:1 on elevated #2d2d2d,
  5.98:1 on #1e1e1e). Same change in `static/js/web-components/shared-styles.ts`
  `.force-dark` block. Fallback literals in components use various hexes with
  the var first — leave untouched fallbacks (var always wins; no dead weight to
  change).
- Verify: no component relies on muted-on-muted; sunken surfaces get ≥4.5.

## TDD execution order (each: Red → Green)

P1 **Variant tokens (library+css)**

- Red: library.test.ts — `Button` / `Text` schemas accept variant, renderer
    output carries `data-variant`, unknown variants rejected by parser.
- Green: schema + component changes.

P2 **Positional binding safety**

- Red: `Text("hi", "title")`, `Button("go", undefined-as-absent, "ghost")`
    positional parse tests (variant last in prop order).
- Green: prop ordering in schemas.

P3 **Stack gap tokens + 4pt card**

- Red: gap `'sm'|'md'|'lg'|'xl'` renders `gap:4px/8px/16px/24px`; free form
    still renders; card gap 12px (CSS assertion on design-system css text).
- Green: schema union + css change.

P4 **Progress + Steps components**

- Red: schema/render tests — `Progress(5, 2, "steps")` renders label
    "2 of 5" (aria attrs); reactive `current` updates; `Steps($i, 3, @A, @B)`
    renders back/next buttons dispatching the action; no buttons when actions
    absent.
- Green: components + css + registry + childrenUnion.

P5 **Muted AA contrast**

- Red: default.css assertions — compute contrast in test (port the python
    helper) pinning `--color-text-muted` = #737373 (light) / #999b9e (dark) and
    ≥4.5 ratio on #ffffff/#f8f9fa/#2d2d2d surface pairs.
- Green: token edits (default.css, shared-styles.ts force-dark).

P6 **Library version bump + stamps**

- Red: tests pin `wiki-core@2` (library.test.ts, page_app_test.go,
    wiki-page-app-host.test.ts).
- Green: version constants + go stamps (setPageApp writes stamps — same
    constant, verify via tests).

P7 **Docs ride-along** (help-page-apps `wiki-core@2`, new components documented
