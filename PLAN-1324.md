# Plan: #1324 — Page apps: PWA install support + bare-app URL mode

Orca Run: run_c809d872fc18 (coordinator: term_7aa80526)

## Goal
Page apps become installable standalone apps: a bare URL mode that renders only the
page app (no wiki chrome), plus PWA install support (manifest, service worker,
install button with Add-to-Home-Screen fallback).

## Shared contract (all workers)
- Bare route: `GET /<page>/bare` → full-viewport page app only; 404 when no
  ```wiki-page-app fence; `Cache-Control: no-store`.
- PWA endpoints: `GET /manifest.json?page=<identifier>` (per-page manifest,
  start_url `/<page>/bare`, scope `/`, display standalone, site icons);
  `GET /sw.js` (static asset, `Service-Worker-Allowed: /`).
- Frontend: `<wiki-pwa-install>` Lit element, `page` attr (identifier), boolean
  `bare` attr switches install-button mode vs link-to-bare-URL mode.
- `bare.tmpl` carries manifest link + `<wiki-pwa-install bare page=…>`.

## Waves
1. **A — Bare mode (Go + templates)**: route, `static/templates/bare.tmpl`,
   fence-or-404, no-store, help_page_apps.md update, Ginkgo tests.
   **C — Install component (frontend)**: `wiki-pwa-install.ts` + tests; SW
   registration in bare mode; beforeinstallprompt → Install button; A2HS
   fallback; wiki-chrome mode links to bare URL. (A ∥ C, disjoint files)
2. **B — PWA backend**: `server/pwa_handlers.go` + wiring in `registerRoutes`
   (after A — same file), `static/pwa/sw.js`, icon PNGs (192/512), manifest
   handler tests. (Depends on A)
3. **Integration + review**: coordinator runs scoped gates (go:test server,
   fe:test touched, fe:lint, fe:typecheck, lint:everything), reconciles, then
   plan-vs-code review worker; commit referencing #1324.

## Non-goals
- No changes to page-app component vocabulary (#1302/#1320 features).
- No offline data sync; SW is a conservative offline shell only.
- No install flow inside normal wiki chrome beyond a link to the bare URL.
